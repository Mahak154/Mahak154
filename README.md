## 💼 Featured Projects

### 📈 High-Frequency Trading System & Simulation Dashboard
> **A high-throughput algorithmic backtesting engine and interactive dashboard simulating quantitative strategies.**
*   **Business Problem**: Simulating and validating algorithmic trading strategies on historical data without risking real capital, ensuring accurate performance metrics (PnL, Win Rate).
*   **Architecture & Tech Stack**: Streamlit, Pandas, NumPy, Matplotlib, Plotly, Python.
*   **Key Features**:
    *   Simulates trading execution with custom parameter tuning (slippage, transaction fees).
    *   Backtested over **91 complex trades**, generating a net profit of **₹9.4K** and demonstrating a capital increase from **₹3.63L to ₹3.72L**.
    *   Renders real-time interactive PnL curves, win-rate distributions, and trade distribution charts.
*   **Scalability & Security**: Optimized feature engineering and data loading structures to handle high-frequency data chunks efficiently.
*   **Engineering Challenge**: Mitigating look-ahead bias and transaction slippage simulation in vectorised backtesting pipelines using Pandas.
*   🔗 **Repository**: [High Frequency Trading System](https://github.com/Mahak154/algorithmic-trading-hft)

### 📊 Data Analysis & Visualization Dashboard
> **A comprehensive multi-variable analytical pipeline and dashboard designed to extract deep insights from complex datasets.**
*   **Business Problem**: Raw multi-variable datasets are difficult to parse and interpret for operational and business decision-making.
*   **Architecture & Tech Stack**: Pandas, NumPy, Seaborn, Matplotlib, Streamlit.
*   **Key Features**:
    *   Implements an automated data cleaning and ingestion pipeline to handle missing values, outliers, and type formatting.
    *   Automatically generates correlation matrices, box plots, and heatmaps for multi-variable datasets.
    *   Interactive widgets allowing users to slice and filter datasets by dimensional attributes in real time.
*   **Production-Readiness**: Features structured modular code adhering to OOP principles for easy extension to new data formats.
*   🔗 **Repository**: [Data Analysis Dashboard](https://github.com/Mahak154/ds_mahak_project)

### 💳 Credit Card Fraud Detection Pipeline
> **A robust machine learning pipeline for detecting anomalous financial transactions under heavy class imbalance.**
*   **Business Problem**: Financial fraud detection requires extremely high recall to catch fraud, while maintaining high precision to prevent customer frustration.
*   **Architecture & Tech Stack**: Python, Scikit-Learn, Pandas, NumPy, Matplotlib.
*   **Key Features**:
    *   Implemented and compared Logistic Regression and Random Forest models on heavily imbalanced datasets.
    *   Addressed class imbalance using SMOTE and custom decision threshold adjustment.
    *   Evaluated performance using Precision-Recall Area Under Curve (PR-AUC) and F1-Score instead of simple accuracy.
*   **Engineering Challenge**: Engineering key statistical features from transaction amounts and timestamps to capture anomalous patterns.
